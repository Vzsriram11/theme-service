# Theme Service

A Spring Boot 3.5 microservice that is part of the ThemeVest platform.

## Technology Stack

* Java 21
* Spring Boot 3.5
* Maven
* REST APIs
* YAML Configuration
* GitHub

## Roadmap

* PostgreSQL Integration
* Spring Data JPA
* Docker
* Kafka
* Kubernetes
* AWS Deployment
* OpenTelemetry
